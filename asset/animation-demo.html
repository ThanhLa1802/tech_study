Ngăn xếp đơn điệu giải next-greater-element trong O(n).

/* đăng ký biến góc để animate được */
@property --ang { syntax: "<angle>"; inherits: false; initial-value: 0deg; }
@keyframes spin-border { to { --ang: 360deg; } }

.glow {
  padding: 1.5px;                       /* độ dày viền */
  animation: spin-border 6s linear infinite;
  background: conic-gradient(from var(--ang),
    transparent 0deg, var(--c) 60deg, transparent 150deg, …);
}
.glow > .inner { background: #0b0b0e; border-radius: 16px; } /* che giữa, chỉ chừa vành */

Mẹo: thẻ trong phủ lên giữa để chỉ còn vành mỏng 1.5px — vành đó chính là conic-gradient đang quay.

2 · Node nhảy trên lưới — transform + keyframes

Chỉ dùng transform: translate() (chạy trên GPU) và opacity, lặp vô hạn bằng ease-in-out. Điểm sáng đi đúng một ô mỗi bước: phải → xuống → trái → lên rồi lặp lại. 
@keyframes node-hop {
  0%, 100% { transform: translate(0, 0);    opacity: .9; }
  25%      { transform: translate(24px, 0); opacity: 1;  }
  50%      { transform: translate(24px, 24px); opacity: .9; }
  75%      { transform: translate(0, 24px); opacity: 1;  }
}
.node { animation: node-hop 4s ease-in-out infinite; }

/* tôn trọng người dùng muốn giảm chuyển động */
@media (prefers-reduced-motion: reduce) { .node, .glow { animation: none; } }
